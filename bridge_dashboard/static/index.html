1. Connect the robot

Checking…

Start the PC-side UR driver here. Klipper starts on its own host and only needs the Ethernet connection to this PC.

Complete arm startup manually

  1. Use your existing UR controls to power the arm and release the brakes.
  2. Select Remote Control, start the saved External Control program, and set the speed slider to 100%.
  3. Check the installation, tool TCP and payload in your existing UR setup. The dashboard keeps those settings unchanged.

Power, brakes, mode selection, and program Load/Play are manual actions. Connect robot only launches the configured PC driver and checks feedback.

Zero G-code A/B/C uses AxisForge’s saved orientation in the robot Base frame. It does not mean zero robot joint angles or zero values in the pendant’s TCP fields. Use the pendant to place the upright nozzle initially; homing checks that pose and preserves its orientation.

    2. ALPS load calibration

    Not run

    Use the teaching pendant for the initial home pose, XY placement and orientation. Place a weighing scale on the buildplate beneath the upright nozzle. After confirmation, the arm finds contact slowly, lifts 5 mm, and waits for you to tare the scale. The Z buttons below become available after taring.

    Adjust the load with Z baby steps

    Use a small stable load shown on the scale as your first weight. Open ALPS Logger → Calibration and log that measured weight with its sensor reading. Adjust to a second distinct stable load and log it there too. Do not assume a target weight from uncalibrated counts.

    One click makes one Z move in the robot Base frame, with XY and orientation held. Travel is limited to 25 mm above detected contact and 0.25 mm below it. Down steps larger than 0.05 mm must finish at least 0.5 mm above contact; use 0.05 mm or finer to apply load. Use Up to unload before finishing. An overload or lost feedback stops the routine.

    3. Home & probe bed

    Checking…

    Place the flat build surface beneath the upright nozzle. After confirmation, a continuous Z search finds its approximate height, then two slower contacts refine the height. Defaults are 10 mm/s for the initial search and 0.2 mm/s for the fine contacts. The arm then moves above the first mesh point and waits for your confirmation before measuring the mesh.

    Bed dimensions and mesh coverage

    G-code X/Y must stay between zero and the bed width/depth, including purge lines and end-of-print parking. Resizing preserves the calibrated physical front-left corner. The selected grid fits inside the edge margin. Save, re-probe, then repeat job preflight; a mesh for a different bed size is rejected.

    Homing and mesh settings

    Loading…
    Saved settings for the next routine

    Slower contacts and repeated measurements improve repeatability; a tighter accepted spread rejects inconsistent readings. Maximum Z spread applies to the two fine homing contacts and to each mesh point. Mesh defaults use 0.1 mm/s, five contacts and a 0.02 mm maximum spread. These settings can be saved with the equipment offline. Saving clears job preflight and applies to the next routine.

    Choose 2–9 points along each axis (4–81 points total); the default is 3×3. The probe area and front-left starting corner stay fixed. Upward lifts and retractions default to 20 mm/s; XY travel uses AxisForge’s configured travel speed. Acceleration and joint limits still apply. After measuring the selected grid, the arm returns to its starting nozzle position. Run this whenever the bed moves. Starting clears saved job preflight.

    4. Job configuration

    Choose which heaters to check. Preflight heats only the selected heaters to their G-code targets, then switches all heaters off before checking the robot. Robot preflight does not move the arm.

    Preflight heater checks

    Configured heaters still follow G-code at Start. If a heater is not configured and its check is off, its commands are ignored for this job. Off targets (0 °C) need no heat test.
